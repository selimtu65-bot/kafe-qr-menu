#  Kampüs Kafe Dijital QR Menü ve Yönetim Sistemi

Bu proje, **BLM2537 Ağ Tabanlı Programlamaya Giriş** dersi 2026-2027 Güz Yarıyılı dönem projesi kapsamında **Selim Tuğra Kayabaşı** tarafından geliştirilmektedir.

## Projenin Amacı
Kafe işletmelerinde müşterilerin masadaki QR kodu okutarak fiziksel menüye ihtiyaç duymadan içecek ve tatlıları inceleyebileceği, sipariş sepeti oluşturabileceği, masa rezervasyonu yapabileceği ve kafe yöneticisinin tarayıcı üzerinden menüdeki ürünleri yönetebileceği (ekleme, listeleme, güncelleme, silme) etkileşimli bir web uygulaması sunmaktır.

## Kullanılan Teknolojiler
* **HTML5** (Semantik etiketler, Tablo ve Form yapıları)
* **CSS3** (Harici stil dosyası, Flexbox, Grid, Medya Sorguları)
* **JavaScript** (DOM manipülasyonu, Olaylar, Form doğrulama, localStorage)

##  Sayfa Yapısı (Site Haritası)
* `index.html` - Ana Sayfa ve Kafe Tanıtımı
* `menu.html` - Kategorili Dijital QR Menü ve Ürün Tablosu
* `sepet.html` - Müşteri Sipariş Sepeti
* `rezervasyon.html` - Masa Rezervasyon Formu
* `yonetim.html` - Menü Yönetim Paneli

##Proje Nasıl Açılır ve Çalıştırılır?
Proje tamamen istemci taraflı (HTML, CSS, JS) olarak çalışmaktadır, herhangi bir sunucu veya veritabanı kurulumu gerektirmez. Aşağıdaki iki yöntemden biriyle çalıştırabilirsiniz:

### Yöntem 1: Visual Studio Code ve Live Server ile Açma (Önerilen)
1. Bu depoyu bilgisayarınıza indirin (`Code` -> `Download ZIP`) veya klonlayın.
2. Proje klasörünü **Visual Studio Code (VS Code)** editörü ile açın.
3. VS Code eklentiler (Extensions) kısmından **Live Server** eklentisinin kurulu olduğundan emin olun.
4. `index.html` dosyasına sağ tıklayıp **"Open with Live Server"** seçeneğine tıklayın. Proje varsayılan tarayıcınızda otomatik olarak açılacaktır.

### Yöntem 2: Doğrudan Tarayıcı ile Açma
1. İndirdiğiniz proje klasörünün içerisindeki `index.html` dosyasına çift tıklayarak doğrudan web tarayıcınızda (Chrome, Edge, Firefox vb.) açabilirsiniz.
